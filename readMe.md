## Сервис Управления Задачами с подключаемыми стартерами логгирования и Kafka.

Это сервис на базе Spring Boot для управления задачами. 
Он предоставляет операции CRUD для задач с поддержкой обмена сообщений 
через Kafka и использованием PostgreSQL в качестве базы данных.
Проект также включает базовую обработку исключений и логирование на базе AOP аннотаций.
Тестирование кода: unite-тесты, интеграционные тесты с подключаемыми TestContainers.

Для запуска приложения в контейнерах Docker и его зависимостей, используйте следующую команду:

```bash
docker-compose up --build
```

Запустится:
- Postgre
- Kafka (2 брокера)
- Zookeeper
- Сервис управления задачами Tasks
