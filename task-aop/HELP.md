# Task Starters

## logging-aop-starter

Реализует сквозное логирование (AOP) входных параметров и результатов выполнения публичных методов.

- Аннотация для избирательного логирования методов;
- Интеграция с `Slf4j`;
- Легкая настройка, не требует дополнительной конфигурации.
- Возможность отключения Kafka-интеграции при помощи `logaspect.enable=false`.
